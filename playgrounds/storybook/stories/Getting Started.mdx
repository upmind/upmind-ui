# Getting Started

Install the Upmind UI Library using your preferred package manager:

```bash
# Using npm
npm install @upmind-automation/upmind-ui

# Using yarn
yarn add @upmind-automation/upmind-ui

# Using pnpm
pnpm add @upmind-automation/upmind-ui
```

Then import the components you need in your Vue application:

```vue
<script setup>
import { Button, Input } from "@upmind-automation/upmind-ui";
</script>
```

## Utilities

The library includes several utility functions to help with common tasks:

- `useStyles`: For managing component styles
- `cn`: For class name composition
- `useThemes`: For theme management
- `useStyleSheet`: For dynamic styles
- `initializeLottie`: For Lottie animations
- `usePointerEvents`: For pointer event handling
- `useForwardPropsEmits`: For prop and event forwarding
