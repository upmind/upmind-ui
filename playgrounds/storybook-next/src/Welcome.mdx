# Upmind UI

**The Upmind design system. One system, every brand.**

Upmind UI powers every Upmind surface — checkouts, client portals, admin areas,
payment pages and off-screen flows — and re-skins completely for every brand
that runs on Upmind.

Use the **Theme** and **Mode** pickers in the toolbar above: every story in
this Storybook re-renders under the selected brand and color mode, live,
with no rebuild. That is the system working as designed — components consume
semantic tokens, never raw values, so a brand is nothing more than a small
set of CSS custom properties.

## How theming works

Upmind UI tokens are layered:

1. **Primitives** — raw OKLCH-derived color ramps, the hand-tuned type scale,
   radius and spacing scales.
2. **Semantic intents** — `primary`, `secondary`, `neutral`, `promo`,
   `danger`, `warning`, `success`, `info`, plus core surfaces (`canvas`,
   `surface`), text roles (`display`, `body`, `muted`, `faint`), the
   decoupled form-`control` accent, and the physical layer: elevation slots,
   the scrim, and the motion duration/easing tokens.
3. **Contextual slots** — what components actually consume:
   `--bg-button-primary-0/1` (gradient-capable), `--radius-slot-card`,
   `--font-family-display`, `--icon-stroke`…

A brand theme is generated by `defineTheme()` from as little as **one hex
value** — contrast pairings are checked against WCAG, dark mode is derived
automatically (brands can even declare a `preferredMode`, like the dark-first
Aurora), and gradients, fonts, radius and type ratio are all dialled in with
single tokens.
