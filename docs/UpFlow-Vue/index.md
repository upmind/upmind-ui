# UpFlow-Vue

Upmind's Vue wrapper for UpFlow (our business logic lib for the FE).

If you're looking into using a different FE framework other than Vue,
it's as easy as creating a wrapper for UpFlow like this one.

## Installation

```
npm install @upmind/flow-vue
```
