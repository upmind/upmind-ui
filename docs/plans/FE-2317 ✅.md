# FE-2317: Bug — Discount value not recorded in cart add/remove dataLayer events

## Problem

When firing `add_to_cart` and `remove_from_cart` dataLayer events, the `discount` field is always `0` despite discounts being correctly applied to price/value fields.

## Root Cause

`parsePrice()` in `basketProduct/utils.ts` (line 256) sets `price.configuration.discount` from `raw.total_discount_amount` / `raw.net_product_discount_amount`. These fields only capture **product-level** discounts — coupon/voucher discounts are NOT reflected in them.

The correct fields are `raw.configuration_total_discount_amount_converted` and `raw.configuration_net_amount_discount_converted`, which are already used for `savingAmount` display and proven correct.

## Fix

```diff
// basketProduct/utils.ts — parsePrice()
     discount: includesTax.value
-      ? raw.total_discount_amount
-      : raw.net_product_discount_amount,
+      ? raw.configuration_total_discount_amount_converted
+      : raw.configuration_net_amount_discount_converted,
```
