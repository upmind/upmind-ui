# ThemeConfigValue

```ts
type ThemeConfigValue = 
  | ReturnType<typeof cva>
  | {
[component: string]: ThemeConfigValue;
};
```

Represents a configuration value for a UI theme. This can be a direct value
(e.g. a string for a CSS class generated by `cva`, or a colour code),
or a nested object representing a configuration for a specific component or part of a component.

## Template

The type of the configuration value.
