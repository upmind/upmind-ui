## 1. Identity

- **Framework:** Svelte 5 (runes-first, `$state`/`$derived`/`$effect`) + Vite 8 + sv-router 0.16.
- **Styling:** hand-rolled SCSS (`<style lang="scss">` per component, `sass` as dev dep). No Tailwind, no shadcn, no UI kit.
- **UI kit:** none. Operating principle 14 was knowingly violated — see §8e.
- **State:** module-level singleton classes with `$state` class fields (`authStore`, `currencyStore`, `brandStore`, `basketStore`).
- **HTTP:** axios, single `HttpTransport` singleton, interceptors own two-prefix routing + auth + currency + error normalisation.
- **Package manager:** npm + npm workspaces (`apps/*`, `libs/*`).
- **Monorepo:** Nx, two storefronts (`apps/website` 5173 public, `apps/customer-panel` 5174 account area), `libs/common` shared core.
- **Cadence:** step mode (`/workshop-feature N` per feature, plan → build → commit).
- **Wall-clock:** not tracked. Commit history shows features 0–6 landed across the day in order.
- **Done:** features 0 (foundations), 1 (auth incl. 2FA), 2 (brand bootstrap + theme), 3 (catalogue), 4 (basket), 5 (address), 6 (payment incl. Stripe + convert + poll). Currency switcher landed. Confirmation page landed.
- **Partial:** none mid-feature.
- **Skipped/doc-only this run:** SDD 07 panel in full (07a confirmation already shipped under feature 6's umbrella; 07b home / 07c pay-invoice / 07d payment-methods / 07e profile-CRUD all unbuilt).
