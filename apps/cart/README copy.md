# Upmind Velia Checkout

The Velia checkout serves as a standalone e-commerce checkout for Upmind. It is a bespoke checkout that is designed to be used with the Upmind platform, based on the Velia UI designs.

The checkout is powered by Upmind Flow, which is a state management library that is designed to handle complex state management in a simple and efficient way, and allows for easy integration with the Upmind platform.

This checkout is also built using the Upmind UI Design System, which is am atomic design system of reusable web components that are designed to be used across the Upmind platform.

**Running the Checkout:**

Launch the Velia checkout using the following command:

```bash
npm run dev
```

This will start a development server and open the playground in your web browser.
