# Upmind override

A single-module guide lives with its module, at `packages/headless/src/modules/<name>/docs/guide.md`. This overrides the package-level default. Use a package-level `docs/guides/` only for a guide that spans modules. No such guide exists today. The corpus indexes the `docs/` set of each module.
