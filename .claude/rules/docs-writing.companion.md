# Documentation writing — Upmind bindings

## Actor-type analogy

Where the base rule gives a neutral "person at the counter" analogy for actor types, the Upmind actor set makes it concrete:

| Concept | Analogy |
|---------|---------|
| Actor types | "Client = customer, Staff = employee behind counter" |

Use the client/staff framing in Upmind docs; the actor set is defined by ADR-001 (Scope-Based Composable Architecture).
