## Artifact filing location

The base rule's "Artifact First" checkpoint files the flow document at this repo's SDD location: **`docs/sdd/{ticket}/`** (one folder per Linear ticket), or inline in the story. The design artifact is the spec; only code once it is solid. The evidence/proof conventions for that same `docs/sdd/<ID>/` tree are governed by `evidence-filing.md`.
